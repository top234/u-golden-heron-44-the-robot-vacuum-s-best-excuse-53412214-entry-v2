## The excuse

> "My bumper logged the crumbs under the table as furniture, so I cleaned around them. I don't argue with my own map."

Length: **114 characters**.

## Why it works

The vacuum thinks like a machine: a bumper reading mislabels crumbs as
furniture, and once that label is on the map, the map is the authority.
It never argues with its own data — it just cleans around the "furniture".
Flat machine voice, a sharp final line.

## How to run

```sh
OUTPUT_DIR=/tmp/out-robot-vacuum-v2 node main.ts
```

This writes the excuse to `$OUTPUT_DIR/entry.txt`.
